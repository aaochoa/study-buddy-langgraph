# Study Buddy Frontend (Next.js)

A modern, high-performance Next.js web application built with **TypeScript**, **App Router**, and **Vanilla CSS Modules**, connecting to the FastAPI / LangGraph Study Buddy agent server.

## Features

- **⚡ Real-Time SSE Token Streaming**: Connects natively to `POST /chat/stream` via Server-Sent Events, rendering tokens as they are generated by LangGraph nodes.
- **🏷️ Multi-Agent Dynamic Routing**: Detects and highlights agent intents:
    - 💬 **Study Chat**: General conversational tutoring and explanations
    - ⚡ **Code Specialist**: Code generation, syntax analysis, and algorithm debugging
    - 📚 **Knowledge RAG**: Semantic retrieval across indexed study documents
- **💻 Markdown & Syntax Highlighting**: Renders markdown with GFM support and custom dark-terminal code blocks with one-click clipboard copying.
- **💾 Session & Thread Persistence**: Manages conversation history in `localStorage`, linked directly to LangGraph `thread_id` checkpoints.
- **🛰️ Live Health & Model Monitor**: Actively polls `GET /health` to display server status, latency, and the primary active LLM model.
- **🛑 Generation Control**: Supports aborting streaming generation in real-time via `AbortController`.
- **🎨 Glassmorphic Aesthetic**: Deep obsidian color scheme, subtle gradients, and micro-animations.

## Getting Started

### 1. Configure Environment Variables

Create `.env.local` (preconfigured by default):

```env
NEXT_PUBLIC_AGENT_API_URL=http://localhost:8000
```

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Run Development Server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Code Quality & Formatting

```bash
pnpm lint           # Run ESLint (Airbnb Extended)
pnpm lint:fix       # Auto-fix lint problems
pnpm format         # Format code with Prettier
pnpm format:check   # Validate formatting
```

### 5. Build for Production

```bash
pnpm build
pnpm start
```
